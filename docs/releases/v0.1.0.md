# FDS Roll Gravity v0.1.0

首次发布：为正弦横摇生成完整的 FDS 重力 RAMP，使用可滚动窗口或控制台展示，不自动保存 FDS 结果文件。

## What's new

### Added

- 按频率、时间间隔、总时长和角幅值计算 x、z 重力分量，y 始终为 0。
- 完整结果窗口，支持复制全部、回到开头和查看末尾。
- 自动包含 0 s 起点和总时长终点；校验无效参数。
- 默认参数：0.05 Hz、0.2 s 采样间隔、300 s、±10°、9.81 m/s²，共 3002 条 RAMP。
- 跨平台 CI、标准库测试、版本及源码包校验、MIT 许可证。

## Install

下载并解压 `fds-roll-gravity-v0.1.0.zip`，安装 Python 3.11–3.13，进入解压目录运行：

```bash
python generate_roll_ramps.py
```

图形窗口需要 Tkinter。无桌面环境请将脚本顶部 `output_mode` 改为 `"console"`。其他参数也在脚本顶部修改。
